# Week 8 – React Hooks (useState, useEffect)

Vite + React app in `myreact-Hookapp/`.

| File | What it does |
|---|---|
| `src/Counter.jsx` | `ClickCounter` – click counter with `useState` (Task 1) |
| `src/EmojeeCounter.jsx` | `EmojiCounter` – Love / Sad / Like counters with images, `useState` + `useEffect` (Task 2, tutorial code) |
| `src/WeatherMoodWidget.jsx` | Portfolio – "My Mood Weather Widget": Sunny / Rainy / Cloudy cards, click count saved in `localStorage` |
| `src/main.jsx` | Renders all components |

Run: `cd myreact-Hookapp && npm install && npm run dev` → http://localhost:5173
