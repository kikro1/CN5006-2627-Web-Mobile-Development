# Week 7 – React: functional components and props

Vite + React app in `my-react-app/`.

| File | What it does |
|---|---|
| `src/Myapp.jsx` | `Welcome` – shows "Hello, {name}" from a prop (Task 1) |
| `src/Product.jsx` | `Product` – price + VAT calculator with an `onClick` handler (Task 2) |
| `src/DiscountCalculator.jsx` | Portfolio task – price after a % discount, with 0–100 validation |
| `src/main.jsx` | Renders the three components (App is commented out) |

Run: `cd my-react-app && npm install && npm run dev` → http://localhost:5173
